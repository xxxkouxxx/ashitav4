| 2月 | 梅（淡いピンク） | フラットホワイト | 春の予感、柔らかい光 |
| 3月 | 桜吹雪 | さくらラテ（ピンク） | 石畳、散りかけの春の午後 |
| 4月 | チューリップ（カラフル） | アイスラテ | 澄んだ青空、春の陽射し |
| 5月 | 藤（薄紫） | コールドブリュー | 藤棚の下、木製テーブル、新緑の風 |
| 6月 | 紫陽花（ブルー系） | アイスコーヒー | 雨粒、濡れた石畳、梅雨の朝 |
| 7月 | ひまわり | アイスラテ | 強い夏の光、グリーンの葉 |

## ヒント文を変更したいとき

`generator.js` の `IMAGE_HINTS` 配列を直接編集してください。

```js
const IMAGE_HINTS = [
    /* 1月 */ '...',
    /* 2月 */ '...',
    // ...
];
```
