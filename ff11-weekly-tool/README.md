# FF11 週報ツール — VANA D'IEL LOG

FF11 の週次活動記録をブラウザ上で作成・管理する静的 Web アプリ。
`index.html` をブラウザで開くだけで動作し、サーバー不要。

---

## 使い方

1. `index.html` をブラウザで開く
2. 左ペイン（フォーム）に入力 → 右ペイン（プレビュー）にリアルタイム反映
3. `💾 保存` で当週分を LocalStorage に保存
4. 下部の **TEMPLATE TOOLS** からコピーして Note / SNS に貼り付ける

---

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | UI レイアウト（左：入力フォーム / 右：プレビュー） |
| `app.js` | フォーム⇔プレビューの同期・保存・モーダル制御 |
| `storage.js` | LocalStorage への週報データ保存・読み込み |
| `generator.js` | コピー用テキスト生成（4種） + 月別画像ヒント |
| `style.css` | ダークテーマ・ゲーム風スタイル |
| `image_hints.md` | 月別 表紙画像ヒント（植物 × コーヒー対応表） |

---

## 入力セクション

| # | セクション | 内容 |
|---|-----------|------|
| INFO | タイトル・総評 | 週報タイトル・1〜2 行の総評 |
| 01 | KPI | オデシー / 装備強化 / フレ・LS活動 / デイリーの目標・結果・判定 |
| 02 | 稼働ログ | 曜日別（月〜金：自由入力、土：ダイバージェンス固定、日：オデシー固定） |
| 03 | KPT | Keep × 2 / Problem × 2 / Try × 2 + 来週の目標 × 3 |

---

## コピーボタン（4種）

いずれも**クリップボードにコピー**されるのみ。ファイルは生成されない。

| ボタン | 形式 | 用途 |
|--------|------|------|
| `✨ Note向けコピー（絵文字版）` | 絵文字 + コードブロック形式 | Note（ブログ）貼り付け用 |
| `📋 全文コピー（マークダウン表）` | マークダウンテーブル形式 | 全セクション完全版 |
| `⚡ 差分のみ（最速版）コピー` | 圧縮テキスト形式 | SNS・Discord 向け最速版 |
| `🔖 タグ一覧コピー` | ハッシュタグのみ | タグ単体が必要なとき |

> **Note向けコピー**には、その月の植物 × コーヒーをテーマにした表紙画像生成ヒントが冒頭に自動挿入される（`generator.js` の `IMAGE_HINTS` 配列で管理）。

---

## データ保存

- 入力データは `LocalStorage` に `ff11weekly_{year}_{week}` キーで保存
- `過去の週報 ▾` ボタンで過去分を参照・読み込み・削除できる
- `新規作成` で当週の空データに切り替え（上書き確認あり）

---

## PDF 保存

- `🖨 PDF保存`（ヘッダー）: 週報全体を印刷ダイアログ経由で PDF 保存
- 各セクション右上の `🖨` ボタン: そのセクションのみ PDF 保存

---

## カスタマイズ

### 固定コンテンツの変更（土・日曜日）

`app.js` の `defaultData()` 内の `log` 配列を編集する。

```js
{ day: '土', hours: '', style: '固定', activity: 'LS ダイバージェンス', fixed: true },
{ day: '日', hours: '', style: '固定', activity: 'オデシー ジェール',   fixed: true },
```

### 月別 画像ヒントの変更

`generator.js` の `IMAGE_HINTS` 配列（インデックス 0〜11）を直接編集する。
詳細は [`image_hints.md`](image_hints.md) を参照。
