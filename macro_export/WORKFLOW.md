# FF11 全キャラ アイテム一覧 Excel 出力 ワークフロー

## 必要なもの

- Ashita v4 + `macro_export` アドオン（ロード済み）
- Python + openpyxl (`pip install openpyxl`)

---

## Step 1: 各キャラのインベントリをCSV出力

### 手動（確実・推奨）

ログイン後、キャラが完全に読み込まれた状態でゲーム内コマンドを実行：

```
/me inventory
```

ログイン直後（HP/MPバーが表示されてから数秒後）に実行すれば全バッグを確実に取得できます。

### 自動（補助機能）

`macro_export` アドオンがロードされていれば、**ログインから約30秒後に自動でCSVが生成**されます。手動実行不要なので便利ですが、タイミングによって一部バッグが空になる場合があります。その場合は手動で `/me inventory` を追加実行してください。

### 自動エクスポートの ON/OFF

```
/me auto off   # 一時停止（ゾーン移動が多いときなど）
/me auto on    # 再開
```

---

## Step 2: Excel を生成

`run_excel.ps1` をダブルクリック、または PowerShell から実行：

```powershell
.\run_excel.ps1
```

出力先：`C:\Ashita-v4beta\export\FF11_all_chars.xlsx`

---

## Excel のシート構成

| シート名 | 内容 |
|---------|------|
| 全キャラサマリー | キャラ別のバッグ別アイテム数一覧（先頭） |
| {キャラ名}_持物 | キャラ別の所持アイテム詳細 |
| {キャラ名}_整理 | 装備セット × マクロ対照（マクロ/装備セットCSVがある場合のみ） |

---

## 補足

- 同じキャラが複数回ログインしても、各ログイン時刻ごとにCSVが別ファイルで生成される
- Excel生成時は**キャラごとに最新のCSV**が自動で選ばれる
- 新しいキャラのCSVが増えたら `run_excel.ps1` を再実行するだけで自動追加される
- マクロ・装備セットのCSVも出力したい場合は `/me export` を実行
